Welcome to Just HTML

Why Just HTML?

In a world where web design often emphasizes complex frameworks and advanced scripting, Just HTML takes a step back to appreciate the beauty of minimalism. By stripping away the layers of CSS and JavaScript with the Bootstrap extention, we can focus on the core elements that make up the web: content and structure.

What You'll Find Here

  • Innovative Layouts : Discover unique and creative ways to structure web pages using only HTML.
  • Retro Aesthetics: Embrace the charm of early web design with simple, yet effective layouts.
  • Inspiration: Get inspired by experimental projects that push the limits of HTML.

Join us on this journey to rediscover the essence of web design with Just Html !
